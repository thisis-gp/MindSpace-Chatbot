## Additional Notes

### Color Palette Reference:
- **Primary Blue**: #4A90E2 (calming, trustworthy)
- **Primary Green**: #7ED321 (growth, wellness)
- **Background Gray**: #F5F5F5 (soft, neutral)
- **Accent Colors**: 
  - Orange/Red for Distress (warning, attention)
  - Purple for Escalation (support, connection)
  - Teal for MCP Server (technical, reliable)

### Style Guidelines:
- **Tone**: Professional, calming, trustworthy
- **Aesthetic**: Modern healthcare/tech hybrid
- **Mood**: Supportive, approachable, not clinical or cold
- **Typography**: Clean sans-serif (e.g., Inter, Roboto, Open Sans)
- **Icons**: Simple, recognizable, consistent style
- **Spacing**: Generous white space for clarity

### Tools for Generation:
- **DALL-E 3**: Use detailed prompts above
- **Midjourney**: Add style parameters like "--style raw --v 6"
- **Stable Diffusion**: Use architecture/technical model
- **Canva/FigJam**: For architecture diagrams (manual creation)
- **Lucidchart/Draw.io**: For architecture diagrams (manual creation)

### File Formats:
- **Card**: PNG or JPG, 1200x600px, RGB
- **Thumbnail**: PNG with transparency, 400x400px, RGB
- **Architecture**: PNG or SVG, 1920x1080px or scalable, RGB
